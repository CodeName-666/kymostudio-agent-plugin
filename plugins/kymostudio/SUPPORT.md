# Support

Maintainer: **Christof Seidel**. Contact: **kontakt@kymotrace.de**.

Report plugin installation, instruction or packaging problems through the
[public issue tracker](https://github.com/CodeName-666/kymostudio-agent-plugin/issues).
Send private reviewer access and application-download questions to the contact
above. Keep credentials and private measurement files out of public issues.

Include client/version, plugin version, the failing operation, a redacted error,
and whether the desktop reports MCP, backend and workspace readiness. Preserve
job IDs when an asynchronous operation has not completed. Use synthetic data
when a reproducible example is needed.

The desktop application and its installer are supplied separately. This plugin
does not provide a public cloud server. No directory approval or provider
endorsement is implied by GitHub availability.
